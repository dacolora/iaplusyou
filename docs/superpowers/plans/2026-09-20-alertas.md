# Pestaña Alertas — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Una pestaña «Alertas» en el proyecto que reúne, calculado al vuelo desde el estado real, todo lo que necesita la atención de la persona (llaves que faltan, correo sin confirmar, worker parado, faltantes del proyecto, decisiones pendientes, fallos), con descartes que vuelven solos cuando la situación cambia y un contador en el sidebar.

**Architecture:** Un módulo `alertas.py` sin Flask recorre una lista de fuentes (cada una en su propio `try/except`) y devuelve dicts con `clave` estable + `huella` de la situación; lo único persistente es la tabla `alerta_descartada` (migración 0014). `dashboard.py` cachea `alertas.visibles(cliente)` 60 s por proyecto, lo expone a toda plantilla con `cliente` en la URL mediante un context processor (burbuja del sidebar, línea del Tablero, pestaña) y agrega dos POST (descartar / restaurar). La lista de llaves de Puesta a punto sale de `dashboard.py` a `llaves.py` (con alias) para que `alertas.py` la lea; gana la tarjeta de WaveSpeed. El Tablero pierde su lista de alertas (queda una línea) y `base.html` pierde el banner del correo.

**Tech Stack:** Python 3 / Flask / SQLAlchemy sobre SQLite (`db.py`, Alembic en `migrations/`), Jinja2 + JS vanilla en `templates/`, CSS en `static/style.css`, pytest.

**Spec:** `docs/superpowers/specs/2026-09-20-alertas-design.md` (todas las secciones; §0 fija que NO hay correo diario).

## Global Constraints

- Ningún valor de llave sale de `llaves.estado` ni llega a una alerta, plantilla, flash o log: solo se miran `bool(os.environ.get(var))` y se nombran variables (spec §9).
- Cualquier texto de error que llega a una alerta pasa por `cola.sin_token` y `cola.recortar(…, 200)`; una fuente que revienta reporta SOLO el nombre de la clase de la excepción (`type(e).__name__`), nunca el mensaje (spec §2.5).
- Nada de este plan gasta créditos, encola tareas, publica ni llama a un proveedor de pago; `meta_conexion.estado` solo se toca a través de `tablero.alertas` (cacheado 10 min) y el Pixel solo desde caché.
- Forma de una alerta (spec §1), siempre con todas las llaves: `clave`, `huella` (sha256 hex de 64), `nivel` ∈ `("bloquea", "atencion", "info")`, `grupo` ∈ `("puesta_a_punto", "faltantes", "decision", "fallos")`, `titulo`, `detalle`, `tab`, `ancla`, `url`, `entidad`.
- Constantes literales: `DIAS_FALLOS = 30`, `MINUTOS_PROMPT_LISTO = 60`, `MINUTOS_WORKER = 30`, `ALERTAS_TTL_S = 60`.
- Textos en español, sin tildes en ids/claves; títulos con los números adentro («2 prompts listos sin generar en Crear»).
- La pestaña Alertas va en `cliente.html` justo después de `tab-tablero` y ANTES de `tab-settings` (los tests de Configuración recortan el HTML desde `<section id="tab-settings"`).
- Tests: `venv/bin/python3 -m pytest -q` en verde al cerrar cada tarea; `python3 -m py_compile <archivo>` antes de cada commit. Sin red en tests.
- Commits en español al estilo del repo (`git log`), terminando con `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.

```python
    Column("huella", String(64), nullable=False),
```

```python
"""
Alertas del proyecto: todo lo que necesita la atención de la persona, en un
solo lugar (pestaña Alertas). Spec: docs/superpowers/specs/2026-09-20-alertas-design.md.

Regla de oro: NADA se almacena salvo los descartes. Cada alerta se calcula al
vuelo desde el estado real (llaves, tablas, archivos del proyecto), así nunca
hay una alerta vieja que ya no corresponda: si algo se resuelve, desaparece
sola. Cada fuente (FUENTES, al final del módulo) corre en su propio
try/except: si una revienta sale una alerta `revision:<fuente>` con SOLO el
nombre de la clase de la excepción (nunca el mensaje, que podría arrastrar un
token) y el resto se calcula igual.

Una alerta es un dict (spec §1) con `clave` estable (`<fuente>:<tipo>[:<entidad>]`)
y `huella` (sha256 de la situación): un descarte vive mientras la alerta
exista con esa misma huella; si cambia la situación, vuelve a mostrarse; si
la alerta desaparece, `visibles` poda el descarte.

Ningún valor de llave sale de aquí (llaves.estado mira solo bool(os.environ));
los textos de error que llegan a una alerta pasan por cola.sin_token y
cola.recortar. Nada de aquí gasta, encola, publica ni llama a un proveedor.
Sin Flask: lo importan dashboard.py y los tests.
"""
import hashlib
import os
from datetime import datetime

import sqlalchemy as sa
from sqlalchemy.dialects.sqlite import insert as insert_sqlite

import cola
import db

BASE_DIR = os.path.dirname(os.path.abspath(__file__))

NIVELES = ("bloquea", "atencion", "info")
GRUPOS = ("puesta_a_punto", "faltantes", "decision", "fallos")
NOMBRES_GRUPO = {"puesta_a_punto": "Puesta a punto pendiente", "faltantes": "Faltantes del proyecto",
                 "decision": "Esperan tu decisión", "fallos": "Fallos y errores"}
NOMBRES_NIVEL = {"bloquea": "bloquea", "atencion": "atención", "info": "info"}
NOMBRES_TAB = {"settings": "Configuración", "catalogo": "Catálogo", "creativeflowplus": "Crear",
               "experimentos": "Experimentos", "sprints": "Sprints", "nicho": "Nicho"}
DIAS_FALLOS = 30
MINUTOS_PROMPT_LISTO = 60
MINUTOS_WORKER = 30
IMAGE_EXTS = (".jpg", ".jpeg", ".png", ".webp")

# (nombre, función(cliente, ahora_iso) -> lista de alertas), en el orden en
# que se muestran dentro de un mismo grupo y nivel. Se llena al final del
# módulo; los tests lo reemplazan con fuentes falsas.
FUENTES = []


def huella(*partes):
    """sha256 hex de la «situación» de una alerta. Sin partes es la huella
    vacía: una constante para las alertas cuya situación no cambia."""
    return hashlib.sha256("|".join(str(p) for p in partes).encode("utf-8")).hexdigest()


def _alerta(clave, huella_, nivel, grupo, titulo, detalle, tab, ancla=None, url=None, entidad=None):
    if nivel not in NIVELES:
        raise ValueError(f"nivel inválido: {nivel}")
    if grupo not in GRUPOS:
        raise ValueError(f"grupo inválido: {grupo}")
    return {"clave": clave, "huella": huella_, "nivel": nivel, "grupo": grupo, "titulo": titulo,
            "detalle": detalle, "tab": tab, "ancla": ancla, "url": url, "entidad": entidad}


def _minutos(desde_iso, ahora_iso):
    """Minutos entre dos ISO (None si alguno no se puede leer)."""
    try:
        return (datetime.fromisoformat(str(ahora_iso)[:19]) - datetime.fromisoformat(str(desde_iso)[:19])).total_seconds() / 60
    except (TypeError, ValueError):
        return None


def _limpio(texto, n=200):
    """Texto de error apto para una alerta: sin tokens y recortado."""
    return cola.recortar(cola.sin_token(texto), n)


# ---------- cálculo ----------

def calcular(cliente, ahora_iso=None):
    """Todas las alertas del proyecto, sin mirar descartes, ordenadas por
    grupo (GRUPOS) y nivel (NIVELES); dentro del mismo nivel, en el orden en
    que las produjo su fuente (sorted es estable)."""
    ahora = ahora_iso or db.ahora()
    out = []
    for nombre, fn in FUENTES:
        try:
            out.extend(fn(cliente, ahora))
        except Exception as e:  # noqa: BLE001 — una fuente rota no tumba las demás ni la página
            out.append(_alerta(f"revision:{nombre}", huella(type(e).__name__), "info", "puesta_a_punto",
                               f"No se pudo revisar {nombre}",
                               f"Falló el cálculo ({type(e).__name__}). El resto de alertas sigue abajo.", "settings"))
    orden_grupo = {g: i for i, g in enumerate(GRUPOS)}
    orden_nivel = {n: i for i, n in enumerate(NIVELES)}
    return sorted(out, key=lambda a: (orden_grupo[a["grupo"]], orden_nivel[a["nivel"]]))


def resumen(lista):
    r = {"n": len(lista), "bloquea": 0, "atencion": 0, "info": 0}
    for a in lista:
        r[a["nivel"]] += 1
    return r


# ---------- descartes ----------

def _descartes(cliente):
    t = db.alerta_descartada
    with db.conectar() as con:
        return {f.clave: (f.huella, f.descartada_en) for f in con.execute(
            sa.select(t.c.clave, t.c.huella, t.c.descartada_en).where(t.c.cliente == cliente))}


def descartar(cliente, clave, huella_):
    """Upsert de (cliente, clave) → huella: un descarte nuevo sobre la misma
    clave reemplaza al anterior."""
    t = db.alerta_descartada
    ahora = db.ahora()
    with db.conectar() as con:
        con.execute(insert_sqlite(t).values(cliente=cliente, clave=clave, huella=huella_, descartada_en=ahora)
                    .on_conflict_do_update(index_elements=["cliente", "clave"],
                                           set_={"huella": huella_, "descartada_en": ahora}))


def restaurar(cliente, clave):
    t = db.alerta_descartada
    with db.conectar() as con:
        con.execute(sa.delete(t).where(t.c.cliente == cliente, t.c.clave == clave))


def _borrar_descartes(cliente, claves):
    t = db.alerta_descartada
    with db.conectar() as con:
        con.execute(sa.delete(t).where(t.c.cliente == cliente, t.c.clave.in_(list(claves))))


def visibles(cliente, ahora_iso=None):
    """calcular() menos las alertas descartadas con la MISMA huella. Devuelve
    {"visibles", "descartadas" (las actuales que coinciden con un descarte,
    con `descartada_en`), "resumen" (de las visibles)}. De paso poda los
    descartes cuya clave ya no existe (la alerta se resolvió), salvo que en
    esta pasada haya fallado alguna fuente (`revision:*`): sus alertas
    podrían faltar por el fallo y se perderían descartes válidos."""
    todas = calcular(cliente, ahora_iso)
    filas = _descartes(cliente)
    vis, desc = [], []
    for a in todas:
        d = filas.get(a["clave"])
        if d and d[0] == a["huella"]:
            desc.append({**a, "descartada_en": d[1]})
        else:
            vis.append(a)
    claves = {a["clave"] for a in todas}
    huerfanas = [c for c in filas if c not in claves]
    if huerfanas and not any(a["clave"].startswith("revision:") for a in todas):
        _borrar_descartes(cliente, huerfanas)
    return {"visibles": vis, "descartadas": desc, "resumen": resumen(vis)}
```

```python
# Caché en proceso de las alertas (spec alertas §5): el context processor las
# pinta en TODA página con <cliente> (burbuja del sidebar, línea del Tablero,
# pestaña), así que se guardan ALERTAS_TTL_S por proyecto. Descartar y
# restaurar invalidan siempre; invalidar_tablero también (las acciones que
# cambian experimentos ya pasan por ahí). Como el tablero, es por proceso de
# gunicorn: aceptable.
ALERTAS_TTL_S = 60
_ALERTAS_CACHE = {}          # cliente -> (monotonic, contexto)
_ALERTAS_LOCK = threading.Lock()


def invalidar_alertas(cliente=None):
    """Olvida las alertas cacheadas de un proyecto (o de todos)."""
    with _ALERTAS_LOCK:
        if cliente is None:
            _ALERTAS_CACHE.clear()
        else:
            _ALERTAS_CACHE.pop(cliente, None)


def _contexto_alertas(cliente):
    """`alertas.visibles(cliente)` con caché de ALERTAS_TTL_S por proyecto."""
    ahora = time.monotonic()
    with _ALERTAS_LOCK:
        entrada = _ALERTAS_CACHE.get(cliente)
        if entrada and ahora - entrada[0] < ALERTAS_TTL_S:
            return entrada[1]
    ctx = alertas.visibles(cliente)
    with _ALERTAS_LOCK:
        _ALERTAS_CACHE[cliente] = (ahora, ctx)
    return ctx


# Lo que llega por formulario al descartar: la clave tiene la forma
# <fuente>:<tipo>[:<entidad>] (spec §1) y la huella es un sha256 hex.
CLAVE_ALERTA_RE = re.compile(r"^[a-z_]+:[A-Za-z0-9_:.\-]{1,180}$")
HUELLA_ALERTA_RE = re.compile(r"^[0-9a-f]{64}$")


@app.route("/cliente/<cliente>/alertas/descartar", methods=["POST"])
def alertas_descartar(cliente):
    """Oculta una alerta hasta que cambie su situación (misma clave, otra
    huella → vuelve). No calcula nada: solo escribe el descarte."""
    clave = (request.form.get("clave") or "").strip()
    huella = (request.form.get("huella") or "").strip()
    if not CLAVE_ALERTA_RE.match(clave) or not HUELLA_ALERTA_RE.match(huella):
        abort(400)
    alertas.descartar(cliente, clave, huella)
    invalidar_alertas(cliente)
    flash("Alerta descartada. Vuelve sola si la situación cambia.", "ok")
    return redirect(url_for("ver_cliente", cliente=cliente, _anchor="alertas"))


@app.route("/cliente/<cliente>/alertas/restaurar", methods=["POST"])
def alertas_restaurar(cliente):
    clave = (request.form.get("clave") or "").strip()
    if not CLAVE_ALERTA_RE.match(clave):
        abort(400)
    alertas.restaurar(cliente, clave)
    invalidar_alertas(cliente)
    flash("Alerta restaurada.", "ok")
    return redirect(url_for("ver_cliente", cliente=cliente, _anchor="alertas"))
```

```python
@app.context_processor
def _alertas_sidebar():
    """`alertas_ctx` ({visibles, descartadas, resumen}, cacheado) para toda
    página con <cliente> en la URL: la burbuja del sidebar (también en las
    páginas de Sprints y Nicho), la línea del Tablero y la pestaña Alertas.
    Fuera para los parciales JSON, sin sesión y para la landing pública. Si
    el cálculo revienta, la página sale sin alertas: nunca se cae por esto."""
    cliente = request.view_args.get("cliente") if request.view_args else None
    if not cliente or "usuario" not in session or request.endpoint == "landing_cliente" or _quiere_json():
        return {}
    try:
        return {"alertas_ctx": _contexto_alertas(cliente)}
    except Exception as e:  # noqa: BLE001 — sin alertas, pero con página
        print(f"[aviso] Alertas de {cliente}: no pude calcularlas: {type(e).__name__}")
        return {}
```
