# Editor capa 5c-1 — textos y gráficos que venden — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que un anuncio armado en el editor salga como se ve: los textos se parten en las mismas líneas en la vista previa y en el video, los emojis salen a color en la final, un texto agrandado no se pone borroso, hay 8 fuentes de anuncio más, guías y avisos de las zonas que tapan TikTok, Reels y Shorts, y un paquete propio de stickers (20 gráficos de un color elegible, 6 plantillas de texto para vender y emojis como sticker).

**Architecture:** El servidor sigue rasterizando todo texto (Pillow); la vista previa lo imita con una **maqueta compartida**: `final_edition/tipografia.py` y su espejo `static/editor/tipografia.js` deciden, con la misma tabla de avances leída de las TTF (`static/editor/tipografia.json`, generada por `final_edition/fuentes.py`), qué caracteres salen, dónde se parte cada línea, cuánto mide la caja y en qué punto va cada letra — los mismos números en los dos motores (tabla de paridad). Eso es el texto **v2** (`estilo.version: 2`); un texto viejo (v1) se produce exactamente como hoy hasta que la persona lo toca. Los emojis salen de una fuente COLRv0 (Twemoji Mozilla) que dibujan Pillow (capa por capa con una copia de la fuente armada en memoria: R1) y el navegador (`@font-face`). La nitidez: el PNG se dibuja al factor de su escala. Las zonas seguras son solo página (`static/editor/zonas.js`). Los stickers son PNG blancos hechos en el repo (`final_edition/stickers.py`) que entran como capas de imagen con `tinte` (`lutrgb` en el render, `destination-in` en la vista).

**Tech Stack:** Python 3 / Flask / Pillow (FreeType con color) / ffmpeg (existente; `lutrgb`); lector propio de TTF con `struct` (sin dependencias nuevas); JavaScript ES2022 en módulos nativos, Canvas 2D (`fontKerning`, `globalCompositeOperation`), CSS Font Loading API (`document.fonts.load`), `localStorage`; `node --test` para lo puro; Flask-Babel (fase 6) para la interfaz.

**Spec:** `docs/superpowers/specs/2026-10-01-editor-capa5c-textos-graficos-design.md` (decisiones D1–D16, formas de datos §2, paridad §3, archivos a bajar §4). Contexto: auditoría post-4b (bugs #3, #8, #9, #19; Parte 3 ítems 1, 5 y 6); capas 4c, 5a y 5b; guía `.claude/skills/editor/SKILL.md`.

**Interfaces:**
- Consumes: `documento._fallar`, `documento._COLOR_SIN_ALFA_RE`, `vista_previa.config_navegador`, `vista_previa.material_para`.
- Produces:
  - `fuentes.FONTS_DIR` (= `static/fonts`), `fuentes.RUTA_EMOJI` (= `static/fonts/emoji/TwemojiMozilla.ttf`), `fuentes.EMOJI_ID = "TwemojiMozilla"`, `fuentes.RUTA_TABLA` (= `static/editor/tipografia.json`).
  - `fuentes.leer_ttf(ruta) -> {"upem": int, "asc": int, "desc": int, "avances": {cp: int}}`: `struct` sobre `head` (unitsPerEm, desplazamiento 18), `hhea` (ascender y descender con signo en 4–7; `desc` = −descender; numberOfHMetrics en 34), `hmtx` (avance del glifo; los glifos ≥ numberOfHMetrics usan el último), `cmap` (subtablas formato 4 de plataforma 0 o 3, y formato 12; la primera que trae un código gana; glifo 0 = sin glifo). Una TTF ilegible → `ValueError` con el nombre del archivo.
  - `fuentes.REPERTORIO = ((0x20, 0x24F), (0x2000, 0x206F), (0x20A0, 0x20CF), (0x2100, 0x214F), (0x2190, 0x21FF), (0x2200, 0x22FF), (0x2300, 0x23FF), (0x25A0, 0x25FF), (0x2600, 0x27BF), (0x2B00, 0x2BFF), (0x1F000, 0x1FAFF))`.

  - `fuentes.hay_emoji() -> bool` (el archivo existe).
  - `fuentes.tramos(avances: dict) -> [[inicio, [avance, …]], …]`: códigos consecutivos juntos, ordenados.
  - `fuentes.generar_tabla() -> dict` = `{"version": 1, "repertorio": [[a, b], …], "fuentes": {id: {"upem", "asc", "desc", "avances": tramos(solo códigos del repertorio)}}, "emoji": {"id": EMOJI_ID, "upem", "asc", "desc", "avances": tramos(…)} | None}` (las fuentes de `catalogo()`; `emoji` `None` sin archivo); `escribir_tabla()` la escribe en `RUTA_TABLA` (JSON con `ensure_ascii=False`, `sort_keys=True`, `indent=None`, separadores `(",", ":")`, fin de línea); `if __name__ == "__main__": escribir_tabla()`.
