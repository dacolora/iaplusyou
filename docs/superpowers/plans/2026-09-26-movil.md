# Celular — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** En pantallas de hasta 760 px la barra lateral del proyecto se esconde y se abre con «☰ Menú» como panel encima de la página; el contenido usa todo el ancho.

**Architecture:** Marcado nuevo en `base.html` (botón en la barra superior, fondo oscuro, script de abrir/cerrar) y `_sidebar.html` (✕); `cliente.html` escribe la pestaña actual en la barra. El `@media (max-width: 760px)` de la barra lateral en `static/style.css` se reemplaza por el del panel deslizable.

**Tech Stack:** Jinja2, CSS, JS sin dependencias, pytest.

**Spec:** `docs/superpowers/specs/2026-09-26-movil-design.md`

## Global Constraints

- Toda regla de la barra superior va acotada a `body > header` / `body.con-sidebar > header` (`tests/test_estilos.py`).
- En escritorio (> 760 px) nada cambia.
- Pruebas: `/Users/colorado/Documents/GitHub/iaplusyou/venv/bin/python3 -m pytest -q -m "not slow"`.

```html
  <script>
    // Menú del celular (spec 2026-09-26): ☰ abre la barra lateral encima de la
    // página; se cierra con la ✕, tocando el fondo, con Escape o al elegir algo.
    (function () {
      var boton = document.getElementById('menu-movil');
      var sidebar = document.getElementById('sidebar');
      if (!boton || !sidebar) return;
      function poner(abierto) {
        document.body.classList.toggle('menu-abierto', abierto);
        boton.setAttribute('aria-expanded', abierto ? 'true' : 'false');
      }
      boton.addEventListener('click', function () { poner(!document.body.classList.contains('menu-abierto')); });
      document.getElementById('sidebar-fondo').addEventListener('click', function () { poner(false); });
      document.getElementById('sidebar-cerrar').addEventListener('click', function () { poner(false); });
      document.addEventListener('keydown', function (ev) { if (ev.key === 'Escape') poner(false); });
      sidebar.addEventListener('click', function (ev) {
        if (ev.target.closest('.sidebar-item, .sidebar-gasto')) poner(false);
      });
    })();
  </script>
  {% endif %}
```
