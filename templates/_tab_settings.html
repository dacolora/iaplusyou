Conectar tu tienda

Conecta tu tienda para traer el catálogo solo (cada 6 h) y, en Shopify y WooCommerce, leer los pedidos que llegan con una pieza en la URL — así un experimento sabe qué vendió aunque no haya Pixel. Solo lectura: nunca se cambia nada en la tienda.

{% if not cifrado_ok %}

Falta FLASK_SECRET_KEY en el .env del servidor: sin ella no se pueden guardar credenciales de tiendas. Ponla y reinicia para habilitar estos formularios.

{% endif %}
Shopify, paso a paso
  1. En el admin de Shopify ve a Configuración › Apps y canales de venta › Desarrollar apps y pulsa Crear una app (ponle un nombre, por ejemplo «creatv»).
  2. En Configurar alcances de la API de administrador marca read_products y read_orders; nada más.
  3. Pulsa Instalar app y confirma.
  4. Copia el Admin API access token (empieza por shpat_): Shopify lo muestra una sola vez.
  5. Abajo, en Conectar tienda › Shopify, pega el token junto con el dominio xxx.myshopify.com.

Qué trae: productos y pedidos con UTM — los experimentos se pueden decidir por ventas aunque no haya Pixel.

WooCommerce, paso a paso
  1. En WordPress ve a WooCommerce › Ajustes › Avanzado › REST API y pulsa Añadir clave.
  2. Descripción «creatv», usuario un administrador, permisos Lectura. Pulsa Generar clave de API.
  3. Copia la Consumer key (ck_…) y el Consumer secret (cs_…): también se muestran una sola vez.
  4. Abajo, en Conectar tienda › WooCommerce, pégalos con la URL de la tienda, que tiene que ir por https://.

Qué trae: productos y pedidos con UTM — los experimentos se pueden decidir por ventas aunque no haya Pixel.

Cómo instalar el Pixel según tu plataforma
  • Shopify: instala la app Facebook & Instagram desde la tienda de apps y, en Data sharing, elige tu Pixel y el nivel «Máximo». Shopify manda las compras solo.
  • WooCommerce: instala el plugin Facebook for WooCommerce y conéctalo con tu Business Manager; el Pixel y los eventos de compra quedan puestos.
  • Otra tienda o landing propia: en Meta Events Manager copia el código base del Pixel y pégalo dentro del <head> de todas las páginas; en la página de gracias agrega el evento Purchase.
